How do I log in via SSH?

The recommended SSH client is OpenSSH - although there are other options. On Windows, you may need to set up OpenSSH first. On Linux and MacOS it should already be available.

If you've correctly configured an AWS SSH key-pair, you'll then be able to log into the admin account without having to enter a password.

Log in via SSH

Then open a terminal and type the command:

ssh admin@example.com

If you are not using the default configured SSH keypair, you may need to provide the path to your private key as well. Do that with the -i switch - like this:

ssh -i path/to/private/key admin@example.com

Complete initialization

Then complete the initialization steps as prompted.

Once your server has been initialized, reloading this page - or browsing to https://example.com - will take you to your server's main page.
